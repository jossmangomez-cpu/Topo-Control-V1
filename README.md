# TopoControl — V2 completa (proyecto Android)
Incluye base persistente SQLite, 15 cuadrillas iniciales escalables, personal, obra, jornada, GPS en primer plano con intervalo de 1 hora, registro de coordenadas y precisión, geocerca configurable conceptualmente (2 km), tarifas y cálculo base de nómina.

IMPORTANTE: esta entrega es el proyecto fuente listo para abrir en Android Studio. El entorno de esta sesión no dispone del Android SDK/Gradle para compilar y entregar un APK binario aquí. Para producción aún deben integrarse mapa cartográfico, autenticación multiusuario, sincronización servidor/offline, geocerca calculada contra coordenadas de cada obra, cierre/aprobación de jornadas y exportación Excel/PDF.
